# DentaFlow

Scheduling and recall reminders for small dental clinics in Spain. Started June 2026.
Live at two clinics in Valencia (Clínica Dental Ruzafa, Clínica Sanz) on a free pilot.

## Stack
Next.js 15, Prisma, Postgres (Supabase), Vercel. Twilio for SMS. Spanish UI.

## Status
- Appointments, recall reminders by SMS: done
- Patient records: in progress
- Billing: monthly plan checkout in progress (src/app/api/checkout, uncommitted), clinics say it fails sometimes
