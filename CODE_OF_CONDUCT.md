# Code of conduct

This repository holds a method with two voices. One of them swears and makes its
point with a sexual metaphor, on purpose, because it sticks. That is a fact about the
skill's output when a user chooses it. It is not a licence for how people treat each
other here.

**The line the skill itself draws**: the metaphor describes work, never a person. It
is about building for the mirror, not about anyone's body, relationships, identity,
or appearance. The same line applies to issues, pull requests, discussions, and
commit messages. Quote the skill's explicit voice when you are discussing the skill's
explicit voice; do not aim it at a contributor, a user, or anyone named in a scenario.

**What is expected**: argue about rails, evidence, and scenarios; assume the other
person wants the skill to work; say what you found and where; accept that the
maintainer decides when a disagreement does not resolve.

**What is not accepted**: insults, harassment, sexual language directed at a person,
publishing someone's private information, and sustained disruption after being asked
to stop. Scenarios and fixtures use invented people; a real person's data in an
issue or a fixture is removed on sight.

**Enforcement**: the maintainer may edit or delete content, close threads, and block
accounts that cross the line, with a short note saying why. Report a problem by
email to the maintainer listed on the GitHub profile, or by opening an issue titled
"Conduct" if you are comfortable doing so publicly.

Adapted in spirit from the Contributor Covenant, shortened to fit a repository whose
own output is deliberately blunt.
